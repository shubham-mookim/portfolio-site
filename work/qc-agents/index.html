QC Agent System

Three agents that write the test suite for React and React Native codebases — then check their own work.

3agents: scan → generate → verify
The problem

Test writing is the work engineers postpone most reliably. A model that generates tests is easy; a model whose tests actually compile and mean something is the whole problem.

What it actually does
01

Scan

An agent walks the codebase and emits structured metadata per file — exports, props, call graph, side effects — instead of dumping source into a prompt.

02

Generate

A second agent writes unit, UI, functional and API tests from that metadata, so it is reasoning over structure rather than guessing from text.

03

Verify

A third agent checks syntax and semantic correctness before anything is accepted. The pipeline refuses its own bad output.

04

Outcome

Manual test-case writing left the QA workflow entirely.
