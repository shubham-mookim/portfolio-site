Colophon · how this is made

This site is served
from a phone.

Not a metaphor. An old Android handset on my desk, running a terminal, serving these bytes to you right now.

The host

The phone runs Termux, which gives it a real Linux shell. Inside that, a dependency-free Node static server binds to 127.0.0.1 only — nothing is exposed on the network — and a Cloudflare tunnel makes an outbound connection to publish it. No ports opened on the router, no inbound holes, no cloud bill.

Deploys are pull-based, because a GitHub runner cannot reach a phone behind home NAT. I push to GitHub, Actions builds the site, and the phone runs one script that pulls the built output and restarts the tunnels. The phone never runs a build — it stays a very simple file server, which is the only reason this is reliable.

The whole control layer is about two hundred lines of shell and one Node file. It serves several sites at once from a manifest; adding another is one line.

Specification
The world

One WebGL fragment shader draws every page — sky, a rolling horizon, caustics, light shafts, marine snow. It takes a single signed uniform: −1 is high above water, 0 is the waterline, +1 is the abyss. The professional/personal switch, and the home page's two-way scroll, just animate that number.

Persistence

The canvas survives navigation. Astro view transitions keep the same WebGL context alive between pages, so the horizon travels instead of restarting.

Framework

Astro, static output. Zero client JavaScript except the shader, the negotiation model on the research page, and a couple of IntersectionObservers.

The live model

The bilateral market on /research is a real simulation running in your browser — nine agents, three tiers, an alternating-offer bargain per round. It is the mechanism behind the research, not a recording of it.

Type

Instrument Serif for anything with a feeling in it, DM Sans for reading, DM Mono for numbers and coordinates.

Photographs

Mine. Paris, Amsterdam and London, autumn 2025 — resized and served as WebP, about 1.2 MB for the lot.

Build

GitHub Actions builds on every push to main and commits the output to a live branch.
